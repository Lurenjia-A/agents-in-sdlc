Revise as alterações e evidências, crie o pull request com `/pr create` e, somente depois da revisão, ative o Agent Merge com `/pr agentmerge`.

> [!IMPORTANT]
> O Agent Merge não ignora aprovações obrigatórias, proteção de branch, filas de mesclagem, configurações do repositório ou permissões ausentes.
