Você preparou um Codespace, instalou o Copilot CLI, adicionou avaliações por estrelas, implementou filtragem, personalizou instruções e uma habilidade, usou o Playwright MCP, criou um agente de QA e autorizou o Agent Merge.

Use **Plan** para pensar na abordagem, **Interactive** para acompanhar alterações focadas e **Autopilot** para tarefas bem delimitadas. Revise sempre o código e as evidências antes de mesclar.

## Mais recursos para explorar

- `/review` para analisar alterações.
- `/rubber-duck` para discutir um problema.
- `/fleet` para orquestrar subtarefas em paralelo.
- `/worktree` para isolar uma tarefa.
