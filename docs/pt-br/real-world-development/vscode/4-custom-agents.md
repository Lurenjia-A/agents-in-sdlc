[Agentes personalizados][custom-agents-concept] são assistentes especializados definidos em arquivos Markdown dentro de `.github/agents`. Revise o agente de acessibilidade existente e use-o no Copilot Chat para implementar um modo de alto contraste.

Agentes personalizados são trabalhadores; [habilidades de agente][agent-skills-concept] são ferramentas reutilizáveis.
