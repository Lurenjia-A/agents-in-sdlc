Agora você fará sua primeira alteração no projeto: exibirá nos cards a avaliação por estrelas que já existe nos dados.

1. Inicie uma nova conversa com `copilot --yolo`.
2. Use `/new` e peça para mostrar `starRating` de 0 a 5, exibindo `No rating yet` quando o valor for `null`.
3. Use `/diff` para revisar cada arquivo alterado.
4. Execute os testes e abra o aplicativo no navegador encaminhado.
5. Crie e mescle seu primeiro pull request.

> [!NOTE]
> Como as respostas de IA são probabilísticas, revise o comportamento e não espere uma implementação específica.
