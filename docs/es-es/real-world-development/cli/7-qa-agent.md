Usa un agente de QA para comprobar el comportamiento de la aplicación con Playwright MCP. Define qué debe verificar, deja que ejecute las pruebas y revisa sus hallazgos.

El agente debe informar de los pasos reproducibles, los resultados y cualquier defecto. Corrige los problemas, vuelve a ejecutar las comprobaciones y conserva una revisión clara antes de crear la pull request.
