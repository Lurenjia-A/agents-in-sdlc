## 什么是模型上下文协议 (MCP)？

MCP 为 Copilot Chat 连接外部工具提供标准方式。Playwright MCP 提供浏览器操作能力。

## 审查 MCP 配置

检查项目中的 MCP 配置、服务器来源和权限，确认它们符合团队要求。

## 添加 Playwright MCP 服务器

按项目说明添加服务器配置，并审查安装或运行请求。

## 启动并信任服务器

启动服务器。只有在确认来源和权限后，才信任该服务器。

## 测试筛选功能

让 Copilot 打开网站、选择筛选条件并验证结果。记录并修复发现的问题。

## 发布分支并创建拉取请求

提交测试和实现更改，发布分支，并在创建拉取请求前审查差异。

## 创建拉取请求

填写清晰的标题和说明，等待检查完成，再请求审查。

## 总结与后续步骤

你已使用 Playwright MCP 从浏览器角度验证功能。下一步创建自定义智能体。
