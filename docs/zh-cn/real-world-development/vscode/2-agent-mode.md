## 场景

使用 Copilot 智能体模式为 Tailspin Toys 添加游戏筛选功能。

## 运行 Tailspin Toys 网站

### 启动网站

按照项目 README 启动开发服务器，并确认它在本地加载。

### 探索网站

浏览游戏列表和详情页，了解筛选功能应如何与现有界面配合。

## 使用 Copilot 探索待办事项

让 Copilot 总结相关 GitHub 议题，并确认验收标准和范围。

## 审查指令文件

确认当前工作树中的指令、工具和测试要求。

## 实现筛选功能

在智能体模式中请求实现筛选。审查计划、文件差异和测试，修复失败项后再接受更改。

## 总结与后续步骤

你已在 VS Code 中使用 Copilot 智能体模式实现功能。下一步使用 Playwright MCP 在浏览器中测试。

### 可选探索练习 – 实现分页

作为额外练习，为游戏列表添加分页，并沿用相同的规划、实现和验证流程。
