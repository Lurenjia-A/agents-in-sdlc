Revisa lo que has aprendido en el taller de GitHub Copilot CLI. Comprueba el diff, ejecuta las pruebas, revisa las pull requests y confirma que la aplicación funciona en el navegador antes de combinar cambios.

Usa este flujo de trabajo en tus proyectos: proporciona contexto, planifica, implementa, prueba, revisa y vuelve a iterar. Mantén siempre la supervisión humana sobre el código generado.
