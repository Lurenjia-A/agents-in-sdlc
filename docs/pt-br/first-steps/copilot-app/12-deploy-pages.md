## Publicar o aplicativo

Neste exercício, você usará o GitHub Copilot para preparar o aplicativo para implantação no GitHub Pages. Revise as alterações sugeridas, execute os testes e publique o site.

1. Abra o workspace do Copilot app.
2. Peça ao Copilot para configurar a implantação no GitHub Pages.
3. Revise os arquivos alterados e execute os testes.
4. Faça commit e push das alterações.
5. Abra a URL publicada no GitHub Pages e verifique o resultado.
