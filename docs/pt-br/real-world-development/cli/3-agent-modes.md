Neste exercício, você implementará filtros por categoria e publicador usando um fluxo orientado por issue.

- Use **Plan** para definir os requisitos e o plano.
- Use **Autopilot** para implementar a alteração.
- Use **Interactive** para revisar o código.
- Execute os testes e valide a funcionalidade no navegador.

Pressione <kbd>Shift</kbd>+<kbd>Tab</kbd> para alternar entre os modos.

> [!NOTE]
> Você continuará usando a mesma conversa e branch para manter o foco nos conceitos principais.
