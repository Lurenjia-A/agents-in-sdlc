O agente de nuvem do GitHub Copilot executa tarefas de forma autônoma e assíncrona. Você explorará como personalizar o ambiente, criar issues bem definidas e atribuí-las ao Copilot.

## Cenários

Atribua ao agente tarefas como adicionar comentários TSDoc às funções exportadas e mostrar jogos relacionados na página de detalhes de um jogo.

## Introdução ao agente de nuvem

O [agente de nuvem](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent#overview-of-copilot-cloud-agent-formerly-copilot-coding-agent) cria um ambiente, trabalha na issue e abre um pull request para revisão.

## A importância de instruções bem definidas

Trate o agente como um parceiro de programação: divida o trabalho em etapas, experimente e adapte o escopo.

## Atribuir uma issue ao agente

1. Acesse o repositório no github.com.
2. Selecione **Issues** e depois **New issue**.
3. Crie a issue com título e descrição claros.
4. Selecione **Assign to Copilot** e depois **Assign**.
5. Acompanhe o pull request e selecione **View session** para observar o trabalho.

> [!NOTE]
> A criação do ambiente e da lista de tarefas pode levar alguns minutos.
