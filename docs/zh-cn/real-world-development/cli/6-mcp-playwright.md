## 场景

自动化测试通过后，还需要从用户角度确认筛选功能。Playwright MCP 让 Copilot 能够在浏览器中操作网站。

## 什么是模型上下文协议 (MCP)？

MCP 是连接智能体与外部工具的开放协议。服务器提供浏览器等工具，智能体按权限调用这些工具。

## 添加 Playwright MCP 服务器

检查项目配置；如果缺少 Playwright MCP，请按照项目指令添加。审查所有配置和安装请求。

## 请求 Copilot 通过 Playwright 探索功能

让 Copilot 启动网站、打开筛选界面、选择条件并验证结果。记录任何错误，修复后重新测试。

## 总结与后续步骤

你已使用浏览器级验证补充自动化检查。下一步创建 QA 自定义智能体。
