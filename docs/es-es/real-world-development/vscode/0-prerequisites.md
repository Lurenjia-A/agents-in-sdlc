Prepara el repositorio de Tailspin Toys y abre un codespace o un contenedor de desarrollo en Visual Studio Code. Necesitarás una cuenta de GitHub con un plan de Copilot compatible y acceso a GitHub Codespaces.

Clona el repositorio de la plantilla, abre la carpeta en VS Code y confirma que Copilot Chat está disponible antes de continuar.
