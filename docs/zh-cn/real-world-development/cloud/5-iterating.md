## 审查工作

查看云端智能体创建的拉取请求、差异、测试和文档，确认每项更改都符合议题。

### 场景

生成式 AI 不会取代设计、测试、安全审查或团队协作。生成的代码仍需完整审查。

## 安全性与 GitHub Copilot 云端智能体

审查权限、依赖项、工作流和外部输入。不要批准无法解释的安装或配置更改。

## 审查生成的文档

检查事实、链接、结构、无障碍性和项目术语，必要时要求智能体修改。

## 请求 GitHub Copilot 更改

在拉取请求中提出具体、可验证的修改要求，并在更新后重新运行检查。

## 审查相关游戏功能

确认数据查询、错误处理、响应式界面和测试覆盖范围符合议题要求。

## 审查无障碍功能

验证键盘操作、语义结构、对比度和替代文本，不要只依据智能体的总结。

## 可选练习 — 继续委派

选择下一项小任务，写清范围和验收标准，再交给云端智能体处理。

## 总结

你已完成从委派、监控到审查和迭代的云端智能体工作流。

## 回顾与后续步骤

继续在 Tailspin Toys 中处理待办事项，或尝试 CLI 和 VS Code 学习路径。
