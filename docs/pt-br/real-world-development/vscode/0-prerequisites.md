Antes dos exercícios do VS Code, crie uma cópia do repositório Tailspin Toys, inicie um [codespace][codespaces] e confirme que o GitHub Copilot Chat está funcionando no editor.

1. Acesse o [template do Tailspin Toys][tailspin-template].
2. Selecione **Use this template** e **Create a new repository**.
3. Abra o repositório no GitHub Codespaces e selecione **Code**.

> [!NOTE]
> Um backlog de issues do GitHub é criado automaticamente quando o repositório é criado a partir do template.

[codespaces]: https://github.com/features/codespaces
[tailspin-template]: https://github.com/github-samples/tailspin-toys
[template-repository]: https://docs.github.com/repositories/creating-and-managing-repositories/creating-a-template-repository
