## 场景

让云端智能体异步实现一项用户体验改进：在游戏详情页添加相关游戏区域。

## 介绍 GitHub Copilot 云端智能体

云端智能体会在隔离环境中探索存储库、编写代码、运行检查并打开拉取请求。

## 明确范围的重要性

任务应包含目标、范围、验收标准和验证方式。清晰的议题能减少来回沟通。

## 本存储库中的自定义指令

云端智能体会读取存储库指令、路径级指令和相关技能。

## 设置云端智能体开发环境

检查存储库提供的设置步骤和所需权限，审查每个安装请求。

## 添加文档

让智能体补充必要的文档，并审查内容是否准确、可访问且符合项目规范。

## 在游戏详情页添加相关游戏区域

分配议题，等待智能体实现功能，然后审查代码、测试和拉取请求。

## 总结与后续步骤

你已将任务交给云端智能体并审查了结果。下一步使用自定义智能体改进工作。
