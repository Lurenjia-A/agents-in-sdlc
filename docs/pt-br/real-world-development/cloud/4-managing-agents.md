O agente de nuvem trabalha de forma assíncrona, mas ainda é importante monitorar as tarefas e orientar uma sessão em andamento.

## Cenário

Depois de atribuir o modo de alto contraste, solicite também um modo claro ao agente.

## Revisar tarefas do agente

1. Acesse a [página de agentes do Copilot](https://github.com/copilot/agents).
2. Selecione uma tarefa em execução e revise as operações realizadas.
3. Examine o painel do pull request e os arquivos alterados.

## Orientar o agente de nuvem

1. Selecione a sessão do modo de alto contraste.
2. No diálogo **Steer active session while Copilot is working**, adicione uma solicitação para incluir o modo claro.
3. Pressione <kbd>Enter</kbd> para enviar.

O Copilot incorporará a solicitação ao fluxo quando concluir a etapa atual.

## Resumo e próximos passos

Você usou a página de agentes para monitorar e orientar tarefas. Agora, continue com [a iteração dos pull requests][next-lesson].
