El **[agente cloud de GitHub Copilot](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** permite que GitHub Copilot trabaje de forma asíncrona en la nube. Asignas trabajo en GitHub y el agente lo recoge en segundo plano —explora el repositorio, realiza cambios y abre una pull request— mientras tú sigues con otras tareas.

En estos ejercicios añadirás instrucciones personalizadas que seguirá el agente cloud y le asignarás una incidencia de GitHub para que implemente el trabajo. Revisarás y usarás agentes personalizados, supervisarás y orientarás las sesiones desde el panel de agentes y terminarás revisando sus pull requests e iterando sobre los resultados.

## Requisitos previos

Antes de asistir a este taller, asegúrate de tener:

- [ ] Una cuenta de GitHub con un plan activo **Copilot Student, Pro, Pro+, Business o Enterprise**
- [ ] El agente cloud de Copilot habilitado para tu cuenta u organización

> [!TIP]
> ¿No tienes un plan de pago? Las personas estudiantes verificadas pueden obtener GitHub Copilot gratis mediante [GitHub Education][callout-student-plan-education]. El plan **Copilot Student** incluye el agente, MCP, la revisión de código y Copilot CLI que usa este taller, por lo que puedes completar todos los ejercicios.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> El agente cloud está disponible en **Copilot Student, Pro, Pro+, Business y Enterprise**; en todos los planes excepto Copilot Free. En Copilot Business o Enterprise, un administrador debe habilitarlo para la organización.

> [!NOTE]
> MCP no se trata en este ejercicio. Para explorar el uso de servidores MCP con Copilot, consulta el [ejercicio de CLI](../cli/) o el [ejercicio de VS Code](../vscode/).
