Revisa tu trabajo, confirma los cambios y crea una pull request desde Copilot CLI.

1. Ejecuta las comprobaciones relevantes y corrige los fallos.
2. Usa `/diff` para revisar cada archivo modificado.
3. Pide a Copilot que cree un commit con un mensaje adecuado.
4. Usa `/pr create` para abrir la pull request.
5. Revisa el diff, la descripción y las comprobaciones antes de combinarla.
