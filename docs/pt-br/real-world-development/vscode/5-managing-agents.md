No Agent Mode, o Copilot explora o código, propõe alterações e executa comandos em tempo real. Acompanhe os tool calls no Copilot Chat, revise os diffs e selecione **Keep** ou **Undo** para aceitar ou rejeitar cada alteração.

Enquanto o agente implementa o modo de alto contraste, oriente a sessão para adicionar também um modo claro.
