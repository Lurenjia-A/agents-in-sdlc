## 场景

智能体可以连续处理多项任务，但你仍需审查进度、控制范围并验证结果。

## 监控 Copilot 的进度

查看会话、工作树、待处理的工具请求和测试输出。

## 引导智能体添加浅色模式

提出明确的后续请求，说明浅色模式的行为、无障碍要求和验收条件。

## 审查工作集

在接受更改前检查所有修改的文件、差异、测试和依赖项。

## 总结与后续步骤

你已学习如何在 VS Code 中监控并引导智能体。审查全部更改后创建拉取请求。
