Revisa las pull requests del agente cloud, solicita ajustes cuando sea necesario y decide los siguientes pasos.

## Revisa e itera

Lee el diff completo, prueba el comportamiento y revisa los comentarios del agente. Si falta algo, deja comentarios claros en la pull request o asigna una tarea de seguimiento. Cuando la solución cumpla los requisitos y todas las comprobaciones pasen, combina la pull request según el flujo de trabajo de tu equipo.

## Resumen

Has configurado instrucciones, asignado trabajo al agente cloud, usado agentes personalizados y supervisado varias iteraciones. Sigue aplicando este ciclo de revisión para mantener el control sobre los cambios generados por agentes.
