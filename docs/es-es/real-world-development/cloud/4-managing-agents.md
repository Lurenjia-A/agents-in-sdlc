Supervisa y orienta las sesiones del agente cloud desde el panel de agentes. Revisa el progreso, los mensajes y las pull requests abiertas.

Si el agente se desvía, añade orientación concreta o actualiza la incidencia. Comprueba siempre los cambios producidos y las comprobaciones automatizadas antes de continuar.
