Explore o GitHub Copilot em todo o ciclo de vida do desenvolvimento de software usando cenários realistas, um aplicativo completo e um backlog compartilhado. Você planejará alterações, criará código, testará o comportamento, revisará pull requests e gerenciará o trabalho com agentes.

## Cenário

Você é um novo desenvolvedor da Tailspin Toys, uma empresa fictícia de financiamento coletivo de jogos de tabuleiro com tema de desenvolvimento. O backlog da equipe já está registrado como issues do GitHub e inclui filtragem, paginação, acessibilidade e padrões de código.

## Escolha seu ambiente

Escolha o ambiente em que prefere trabalhar. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente agêntico no terminal com os modos Plan e Autopilot, instruções, habilidades, agentes personalizados, Playwright MCP, Agent Merge e comandos de barra.

### [GitHub Copilot app][app]

Execute sessões paralelas, alterne modos, colabore em canvases e gerencie issues e pull requests no aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues a um agente assíncrono, acompanhe seu trabalho e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces com Agent Mode, servidores MCP e agentes personalizados.
