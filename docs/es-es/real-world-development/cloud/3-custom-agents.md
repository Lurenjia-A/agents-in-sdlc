Revisa y usa agentes personalizados para dar al agente cloud experiencia especializada, como accesibilidad, seguridad o pruebas.

## Crea un agente personalizado

Crea un archivo Markdown en `.github/agents` con frontmatter `name` y `description`, seguido de las instrucciones del agente. Mantén el alcance claro y especifica las comprobaciones que debe ejecutar.

Asigna otra incidencia y selecciona el agente personalizado. Revisa cómo aplica sus instrucciones y comprueba los resultados en la pull request.
