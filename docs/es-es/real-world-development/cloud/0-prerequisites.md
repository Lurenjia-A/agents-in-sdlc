Antes de comenzar los ejercicios del agente cloud de Copilot, prepara todo lo necesario. Crearás tu propia copia del repositorio Tailspin Toys y abrirás un [codespace][codespaces] para editar archivos de instrucciones y revisar el trabajo del agente cloud.

## Configura el repositorio del laboratorio

1. En una ventana nueva del navegador, ve a la [plantilla de Tailspin Toys][tailspin-template].
2. Crea una copia seleccionando **Use this template** y después **Create a new repository**.
3. Si participas en un evento de GitHub o Microsoft, sigue las instrucciones de las personas mentoras. De lo contrario, crea el repositorio en una organización donde tengas acceso a GitHub Copilot.
4. Anota la ruta del repositorio (**organization-or-user-name/repository-name**).

## Crea un codespace

1. Ve al repositorio que acabas de crear.
2. Selecciona el botón verde **Code**.
3. Selecciona la pestaña **Codespaces** y el botón **+** para crear un codespace.

La creación tardará varios minutos. Puedes aprovechar ese tiempo para explorar otras funciones de GitHub Copilot.

> [!CAUTION]
> Volverás al codespace en un ejercicio futuro. Por ahora, déjalo abierto en una pestaña del navegador.

> [!NOTE]
> Este taller está diseñado para ejecutarse en un codespace o en un [contenedor de desarrollo][dev-containers] local. Si prefieres trabajar localmente, abre el repositorio clonado en VS Code y selecciona **Reopen in Container** cuando se te solicite.

Has creado una copia del repositorio del laboratorio y comenzado a crear el codespace que usarás junto al agente cloud de Copilot.
