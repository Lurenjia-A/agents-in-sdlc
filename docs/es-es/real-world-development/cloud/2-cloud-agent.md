Asigna una incidencia de GitHub al agente cloud de Copilot y deja que explore el repositorio, implemente el cambio y abra una pull request.

## Escenario

Elige una incidencia del backlog de Tailspin Toys con requisitos claros. Revisa su descripción y asigna la incidencia al agente cloud desde GitHub.

## Revisa el trabajo

Supervisa la sesión desde el panel de agentes. Cuando el agente abra la pull request, revisa el diff, los comentarios y las comprobaciones. No combines los cambios hasta entender la solución y confirmar que las comprobaciones necesarias han pasado.
