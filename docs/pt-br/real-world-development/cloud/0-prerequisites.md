Antes de começar os exercícios do agente de nuvem do Copilot, crie sua própria cópia do repositório Tailspin Toys e um [codespace][codespaces] para editar arquivos de instruções e revisar o trabalho produzido pelo agente.

## Configurar o repositório do laboratório

1. Em uma nova janela do navegador, acesse o [template do Tailspin Toys][tailspin-template].
2. Selecione **Use this template** e depois **Create a new repository**.
3. Siga as instruções dos mentores ou crie o repositório em uma organização na qual você tenha acesso ao GitHub Copilot.
4. Anote o caminho do repositório (**organization-or-user-name/repository-name**).

## Criar um codespace

1. Acesse o repositório criado.
2. Selecione o botão verde **Code**.
3. Selecione a guia **Codespaces** e o botão **+** para criar um codespace.

[GitHub Codespaces][codespaces] é um ambiente de desenvolvimento na nuvem que permite escrever, executar e depurar código no navegador.

> [!CAUTION]
> Você voltará ao codespace em um exercício futuro. Por enquanto, deixe-o aberto em uma guia do navegador.

## Resumo

Você criou uma cópia do repositório e iniciou o codespace que usará com o agente de nuvem do Copilot.
