## 场景

实现、指令、技能和 QA 配置已准备就绪。现在审查完整差异并创建拉取请求。

## 介绍 Agent Merge

Agent Merge 可帮助智能体检查拉取请求状态、处理审查意见并在满足条件后合并。

## 使用 Agent Merge 管理 PR

让 Copilot 总结差异、检查必需工作流和审查意见。仅在所有检查通过、差异符合预期时批准合并。
