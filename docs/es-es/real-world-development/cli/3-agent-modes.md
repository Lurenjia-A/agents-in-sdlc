Usa los modos Plan y Autopilot de GitHub Copilot CLI para planificar e implementar una funcionalidad mayor a partir de una incidencia del backlog.

## Escenario

Selecciona la incidencia de filtrado de Tailspin Toys. Primero pide un plan que enumere los archivos, riesgos, pruebas y pasos necesarios. Revisa el plan antes de permitir que Copilot implemente los cambios.

Después, usa Autopilot para que el agente avance por los pasos aprobados. Supervisa las acciones, revisa el código generado y ejecuta las comprobaciones del proyecto.
