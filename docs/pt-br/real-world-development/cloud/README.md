O [agente de nuvem do GitHub Copilot](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent) permite que o GitHub Copilot trabalhe de forma assíncrona na nuvem. Você atribui o trabalho no GitHub, e o agente explora o repositório, faz alterações e abre um pull request enquanto você realiza outras tarefas.

Nestes exercícios, você adicionará instruções personalizadas, atribuirá issues ao agente, revisará agentes personalizados, acompanhará sessões no painel de agentes e iterará sobre os pull requests gerados.

## Pré-requisitos

Antes de participar deste workshop, verifique se você tem:

- [ ] Uma conta do GitHub com um plano **Copilot Student, Pro, Pro+, Business ou Enterprise** ativo
- [ ] O agente de nuvem habilitado para sua conta ou organização

> [!NOTE]
> O agente de nuvem está disponível em todos esses planos, exceto no Copilot Free. Nos planos Copilot Business e Enterprise, um administrador precisa habilitá-lo para a organização.
